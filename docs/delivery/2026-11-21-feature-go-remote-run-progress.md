# 远程备份执行进度

## 任务背景

点击远程备份的“立即执行”后，需要立即看到当前步骤，并在多个目录、多个上游间持续展示执行位置。

## 实现内容

- 后端在已有执行记录 JSON 中保存可选的 `progress`，表示排队、检测 SSH 连接与打包工具、打包并拉取目录、校验本地归档、上传到上游、等待上传重试和执行结束。目录及上游序号从 1 开始。
- SSH 打包与拉取使用同一条字节流，作为同一个步骤展示。手动上传重试先校验本地归档，再上传失败项，继续复用已有归档。
- 启动请求期间按钮显示“正在启动…”，收到响应后立即打开执行详情。任务卡片、执行历史和详情显示当前步骤、目录、上游及尝试次数；自动退避期间显示预计重试时间。
- 进度条按成功完成的目录数计算，并显示成功上传份数。它表示任务完成情况，不表示字节传输百分比。
- 轮询在上次请求结束后等待 1 秒，忽略过期响应。刷新失败时保留最后进度并提示自动重试；选中记录超出最近 50 条列表时单独读取，刷新或重试后仍保留详情。
- 成功、失败、部分成功、取消和重启恢复均结束进度。已有执行记录没有 `progress` 时兼容显示通用状态。

## 影响范围

- `internal/db/remote.go`：增加执行进度结构。
- `internal/remote/execute.go`、`service.go`：持久化各阶段及重试、结束状态。
- `web/src/components/RemoteRunProgress.tsx`、`pages/RemoteBackupsPage.tsx`：展示进度、即时反馈与轮询恢复。
- 前端类型、API、中英文语言文件及后端测试同步补齐。

没有新增依赖、配置项或数据库迁移，继续使用已有执行列表与详情接口。
