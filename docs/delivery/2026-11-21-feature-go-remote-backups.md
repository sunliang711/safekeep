# 远程目录备份交付说明

日期：2026-11-21

## 功能与入口

管理端新增「远程备份」，分为备份任务、远程主机和执行历史。

1. 添加远程主机，填写地址、SSH 端口及登录用户，自动生成独立 Ed25519 密钥。
2. 复制公钥到目标登录用户的授权文件中。Linux/macOS/BSD 通常为 `~/.ssh/authorized_keys`；页面提供权限设置说明及 Windows OpenSSH 文件位置说明。
3. 手动「检测连接与工具」，首次成功公钥认证时登记服务器指纹。以后主机密钥变化会拒绝连接；自动执行不会自动登记未知主机。
4. 创建任务，配置源目录、每目录排除规则、统一上游父目录、多个目标上游、Cron、任务时区和超时时间。
5. 可以定时或立即执行，从执行历史查看每个目录及每个上游的结果。

## 归档与对象路径

每次全量备份，每个源目录生成一个 `tar.gz`。归档中的条目相对于源目录，包含隐藏文件；不主动跟随目录内的符号链接。

路径格式：`<统一父目录>/<YYYY>/<MM>/<完整源路径编码>_<执行编号>.tar.gz`。

例如：`vm001/2026/11/!var!lib!my_sql_<执行编号>.tar.gz`。

年份、月份按任务时区和该次执行开始时间生成。同一执行的多个目录使用相同执行编号。

| 原字符 | 编码 |
|---|---|
| `/` | `!` |
| `!` | `~!` |
| `~` | `~~` |
| Windows `\` | `~^` |
| Windows `:` | `~;` |

编码可逆，保留原路径中的下划线。源路径编码后最多 180 字节，超过时拒绝保存并提示，避免生成过长的单个文件名。

## 远程环境与排除规则

- 通过 SSH 原生客户端库连接，无需安装 SafeKeep Agent。
- POSIX 环境检测 `uname` 及实际 `tar.gz` 归档能力，要求 tar 支持 gzip、`--exclude` 和 `-T`。缺少能力时健康状态为失败，返回安装提示。
- Windows 适配使用 PowerShell 和 `tar.exe`；临时归档通过标准输出字节流传回，避免 PowerShell 文本转换。临时文件在命令结束时删除。
- 每 30 分钟健康巡检已登记指纹的主机，任务执行前再次检测。
- 排除规则为 tar 通配符，每行一条，匹配源目录内的相对路径，例如 `*.log`、`./cache`、`./node_modules`；本期不提供正则模式。
- POSIX 直接流式打包拉取，不在远程落完整压缩包。Windows 暂存压缩包，需要相应远程临时空间。
- Shell 和 PowerShell 参数均按各自规则引用，防止目录或排除规则中的引号及命令替换字符改变命令含义。

## 上传、失败与资源回收

- 复用既有 Provider，支持现有各类上游及代理配置。归档遵循系统单文件大小、每日流量熔断、SMTP 告警和缓冲容量检查。
- 同一任务禁止重叠执行。远程任务并发上限使用启动时的系统 Worker 并发数；超时覆盖排队、SSH、打包、拉取、上传和自动重试。
- 一个目录失败后继续处理其他目录；所有目录及上游结果汇总为成功、部分成功或失败。
- 每个上游按系统最大重试次数自动重试，使用指数退避。手动重试复用原归档、原对象路径及目标上游，只上传未成功项，不再次连接 SSH。
- 重试前校验本地归档的大小与 SHA-256，已成功的上游不会重复上传。上传全部成功后立即清理该目录归档。
- 失败归档保留 72 小时，由巡检回收；清理与重试互斥，并回收无执行记录引用的过期孤儿归档。
- 打包失败或归档已清理时需要重新执行任务。服务重启后将中断的执行标记为失败，保留可用归档供手动重试。
- 删除任务会保留执行历史及云端备份；删除后不再支持通过该任务进行上传重试。
- 不提供上游备份的自动清理或保留策略。

## 存储与迁移

新增 SQLite 表 `remote_hosts`、`remote_backup_jobs`、`remote_backup_runs`，启动时自动创建。

SSH 私钥使用既有 AES-GCM 主密钥加密，API 不返回私钥及本地缓冲路径。迁移包包含远程主机、密钥和任务配置；导入时重加密密钥并重映射主机、任务及上游引用。选择导出任务历史时同时包含远程执行历史，不迁移本地缓冲文件。旧版迁移包兼容。

新增管理 API 均位于 `/admin/api/v1/remote-backups`，要求管理员登录：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET / POST | `/hosts` | 列表 / 创建主机并生成密钥 |
| PUT / DELETE | `/hosts/{id}` | 修改 / 删除主机 |
| POST | `/hosts/{id}/check` | 手动检测连接及工具，首次登记主机指纹 |
| GET / POST | `/jobs` | 列表 / 创建任务 |
| PUT / DELETE | `/jobs/{id}` | 修改 / 删除任务 |
| POST | `/jobs/{id}/run` | 立即执行，返回 202 和执行记录 |
| GET | `/runs?job_id=` | 最近 50 次执行，可按任务过滤 |
| GET | `/runs/{id}` | 单次执行详情 |
| POST | `/runs/{id}/retry` | 重试失败上传，返回 202 |

主机检测结果通过 `health_status` 和 `health_error` 返回；检测失败仍返回主机记录。配置错误返回 400，不存在返回 404，重复名称、重叠执行或配置被引用返回 409，未登录返回 401。
