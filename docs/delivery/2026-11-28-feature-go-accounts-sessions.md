# 账户与会话交付说明

## 功能与使用入口

“系统配置 → 账户与会话”提供当前账号密码修改、活跃登录会话查看及控制台账号管理。会话显示来源 IP、浏览器信息、最后活跃时间、到期时间和当前会话标记。用户可以逐条注销自己的会话；注销当前会话需要确认，完成后退出至登录页。

## 账号角色与权限

系统管理员具有完整控制台权限，可创建管理员或只读运维账号、切换角色、启用或停用账号、重置密码。上述管理操作要求输入操作者本人的当前密码。创建账号默认选择只读运维角色。

只读运维账号可以查询概览、备份任务与文件、上游与代理、客户、定时任务、远程备份及审计信息，并管理自己的密码和会话。只读账号无法执行备份上传、重试、配置修改、任务触发、迁移导出或导入，无法查看密钥明文、系统参数、SMTP 配置及其他账号列表。服务端使用明确的路由白名单校验只读权限，未声明的接口默认拒绝。

系统始终保留至少一个启用的系统管理员。停用当前登录账号会被拒绝；最后一个可用管理员的降级或停用会被事务保护拒绝。并发操作同样适用该约束。

## 会话生命周期

登录会话持久化存储，有效期为 24 小时；最后活跃时间最多每分钟更新一次。服务端只存储登录令牌的摘要，每次受保护请求均检查会话记录。会话被注销后，原 Cookie 和 Bearer 凭据均无法继续访问。

退出登录会删除当前会话。修改自己的密码会撤销原有会话，并向当前设备签发新的会话以保持登录。管理员重置自己的密码同样轮换当前会话；重置其他账号密码、停用账号或改变账号角色会撤销目标账号会话。账号重新启用后，旧会话不会恢复。角色变更涉及当前账号时，需要重新登录。

账号创建、角色与状态修改、密码重置以及会话注销均记录审计。审计内容不包含密码或登录令牌。登录身份或角色切换时，页面内存状态会重新初始化。

## 升级与迁移

服务启动时自动创建会话存储并补充账号角色字段。已有账号保留系统管理员身份。升级前签发的登录凭据需要重新登录；业务 API 客户密钥的认证方式保持一致。

环境迁移包保存账号角色。没有角色字段的旧迁移包按系统管理员身份处理。账号被迁移包覆盖时，其原有会话会撤销；迁移导入结果必须保留至少一个启用的系统管理员。登录会话不会随环境迁移包转移。

管理员救援重置会恢复目标账号的管理员身份，并撤销其原有登录会话。

## 配置与依赖

无需增加环境变量、外部服务或依赖。

## 验证结果

- 前端类型检查与生产构建通过。
- 全量后端测试与竞态检测通过，静态检查通过。
- 会话唯一性、持久化、到期过滤、活跃时间更新、注销后的 Cookie 与 Bearer 拒绝、跨账号隔离均通过验证。
- 密码二次验证、只读访问限制、角色与启停变更后的会话撤销、最后管理员并发保护均通过验证。
- 账号角色迁移和旧迁移包兼容性通过验证。
- 浏览器验证覆盖账号创建、只读登录、权限入口隐藏、敏感接口拒绝、当前会话注销，以及桌面与窄屏布局。
