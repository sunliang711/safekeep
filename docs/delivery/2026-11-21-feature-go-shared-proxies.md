# 可复用代理与上游选择

日期：2026-11-21
版本：v0.1.3

## 任务背景

将上游内嵌的代理配置独立管理，支持添加多个代理，由各上游选择代理或直连，并复用已有代理。

## 实现方案与变更

- 数据库新增 `proxies` 表、唯一代理名称、上游 `proxy_id` 外键与索引。
- 旧数据库启动时在事务内迁移内嵌代理，保留认证密文，迁移可重复执行；旧接口写入的内嵌代理同步转换为独立记录。
- 管理接口新增代理列表、新增、编辑、删除和密码查看；复用管理员鉴权与审计。省略密码保留原值，显式空字符串清除密码。
- 上游表单使用「直连／已保存代理」下拉框，页面通过左侧「上游」、右侧「代理」两个 Tab 切换，默认显示上游，代理页提供代理管理与连接测试，中英文文案同步更新。
- 数据读取统一解析所选代理，覆盖存储上传、下载、连接测试以及 Dropbox Token 换取和刷新。修改代理时事务更新关联上游版本、重置测试状态，后续请求重建缓存客户端。
- 删除代理时检查引用，并由外键限制直接删除，避免连接方式意外改变。
- 配置导入导出保留共享关系和未使用代理，支持代理冲突预检及合并映射，兼容旧版迁移包；无效引用使整次导入回滚。

主要涉及 `internal/db`、`internal/server`、`internal/migration`、Web 上游/迁移/审计页面和文档。

## 接口

- `GET /admin/api/v1/proxies`
- `POST /admin/api/v1/proxies`
- `PUT /admin/api/v1/proxies/{id}`
- `DELETE /admin/api/v1/proxies/{id}`
- `GET /admin/api/v1/proxies/{id}/secrets`
- 上游创建/更新支持 `proxy_id`，空字符串表示直连。
- 代理连接测试沿用 `POST /admin/api/v1/upstreams/test-proxy`，支持指定 `proxy_id`。

## 配置与依赖

无新增环境变量或依赖。沿用 SQLite、现有代理客户端和 AES-GCM 凭证加密。

## 行为边界

代理配置更新影响后续请求；已经开始的传输可能继续使用原连接。每个上游选择一个代理，暂不引入自动切换或负载均衡。旧版字段保留用于兼容迁移。
